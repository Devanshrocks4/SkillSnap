# 🎬 Demo Script

A 5-minute hackathon demo of SkillSnap.

---

## Setup

- Open `skillsnap.ai` in a fresh browser
- Have three tabs ready: Landing, Recruiter dashboard, Candidate dashboard
- Pre-load data so the demo is instant

---

## Script (5 min)

### 0:00 — 0:30 · Hook

> "Hi, I'm [name] and I built **SkillSnap** — an AI-powered recruitment platform that screens resumes, ranks candidates, and evaluates interviews in seconds.
>
> Recruitment is broken. Recruiters spend 20 hours per job screening resumes. Candidates wait weeks for a reply. We fix that."

Show: Landing page → scroll through hero → "shipped in minutes" tagline.

---

### 0:30 — 1:30 · Recruiter flow (the "wow" moment)

> "Let me show you the recruiter experience."

1. Click **Try live demo → Recruiter**
2. Land on dashboard → show stats + hiring funnel + weekly activity
3. Click **AI Screening** in sidebar
4. Select a candidate → watch AI report generate
5. Point to: score, summary, matched vs missing skills, recommendation
6. Click **Shortlist**

> "What used to take 30 minutes now takes 30 seconds — and every decision is explainable."

---

### 1:30 — 2:30 · Interview evaluation

> "Now let's evaluate an interview."

1. Click **Interviews**
2. Show upcoming + completed list
3. Open the AI evaluator panel
4. Paste a sample transcript (or edit the prefilled one)
5. Click **Evaluate with AI**
6. Show: 4 scores, highlights, concerns, recommendation

> "Gemini reads the transcript and scores communication, confidence, and technical depth — exactly what a senior recruiter would do."

---

### 2:30 — 3:30 · Candidate flow

> "Now from the candidate's side."

1. Click **Try live demo → Candidate**
2. Land on overview → show AI profile summary + profile strength
3. Click **Browse Jobs** → show "AI-matched picks" with match %
4. Click **Apply now** → show status in **My Applications**
5. Click **AI Insights** → skills to grow + market insights

> "Candidates get personalized job matches and know exactly what skills to develop to improve their odds."

---

### 3:30 — 4:30 · Admin + Analytics

> "Finally, platform-wide intelligence."

1. Click **Try live demo → Admin**
2. Show platform overview + system health
3. Click **Global Analytics** → hiring velocity, hires by role type, platform metrics
4. Click **Settings** → show security toggles + AI config

> "Admins see the whole hiring machine in one view — and can tune the AI in real time."

---

### 4:30 — 5:00 · Close

> "SkillSnap is built on React + Firebase + Gemini — deployed to Netlify in under 5 minutes. It's production-ready, fully responsive, and ships with security rules, RBAC, and audit logs.
>
> Recruitment shouldn't feel like 2009. With SkillSnap, it doesn't."

Show: architecture slide or GitHub README.

> "Thank you — questions?"

---

## Tips

- **Rehearse 3x** — 5 minutes is unforgiving.
- **Use real data** — mock data looks fake.
- **Have a backup recording** — live demos fail.
- **Emphasize explainability** — judges love "the AI tells you *why*".
- **Call out security** — Firebase rules, RBAC, secrets — this separates toys from products.
